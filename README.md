# Fraud Detection in Financial Transactions Using Metaheuristic Methods for Highly Imbalanced Datasets

## Cel projektu

Celem projektu jest opracowanie oraz porównanie metod wykrywania oszustw w transakcjach finansowych z wykorzystaniem metaheurystyk w warunkach silnie niezrównoważonych danych.

## Zakres projektu

* analiza problemu wykrywania oszustw w transakcjach finansowych,
* analiza problemu niezrównoważonych danych,
* porównanie metod balansowania danych, m.in. oversampling, undersampling oraz SMOTE,
* zastosowanie wybranych metaheurystyk, w szczególności Genetic Algorithm (GA) oraz Particle Swarm Optimization (PSO),
* implementacja i optymalizacja wybranych modeli uczenia maszynowego,
* przeprowadzenie eksperymentów porównawczych,
* ocena modeli z wykorzystaniem metryk Precision, Recall oraz F1-score,
* analiza wyników i sformułowanie wniosków dotyczących skuteczności zastosowanych metod.

## Technologie

* Python
* Scikit-learn
* Pandas
* NumPy
* XGBoost
* CatBoost
* Matplotlib

## Główne porównania

W ramach eksperymentów porównane zostaną różne metody radzenia sobie z niezrównoważeniem danych oraz różne podejścia do optymalizacji modeli z wykorzystaniem metaheurystyk.

Głównymi kryteriami oceny będą **Precision, Recall oraz F1-score**.
