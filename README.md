# raud-detection-in-financial-transactions-using-metaheuristic-methods-for-highly-imbalanced-datasets
Celem pracy jest opracowanie oraz porównanie metod wykrywania oszustw w transakcjach finansowych z wykorzystaniem metaheurystyk w warunkach silnie niezrównoważonych danych.

Zakres pracy:
Analiza problemu wykrywania oszustw w transakcjach finansowych ze szczególnym uwzględnieniem niezrównoważonych danych.
Przegląd metod radzenia sobie z niezbalansowanymi danymi (np. oversampling, undersampling, SMOTE).
Przegląd wybranych metod, w tym metaheurystyk wykorzystywanych w celu wykrycia oszustw (np. algorytm genetyczny, PSO).
Implementacja wybranych modeli.
Przeprowadzenie eksperymentów porównawczych dla różnych metod optymalizacji i podejść do radzenia sobie z niezrównoważeniem danych.
Ocena jakości modeli przy użyciu odpowiednich metryk (np. precision, recall, F1-score) oraz porównanie skuteczności zastosowanych podejść.
Sformułowanie wniosków dotyczących efektywności metaheurystyk w zadaniu wykrywania oszustw przy silnie niezrównoważonych danych.
